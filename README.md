# Ellah's Birthday Website 🎉💖

A beautiful, self-contained birthday website for Ellah May Tomilluso's 19th birthday, built using the reference project with improvements:

## Features:
- Romantic birthday message and love letter
- Interactive photo collage (14 photos) with hover effects
- Dedicated full-screen collage page (collage.html)
- Pointy-edged containers (clip-path octagon)
- Animated gradient background
- Confetti explosion on load, scroll, and click
- Fully responsive mobile-friendly design
- Google Fonts (Dancing Script, Poppins)

## Files:
- `index.html` - Main birthday page
- `collage.html` - Full photo collage
- `style.css` - Styles with animations
- `script.js` - Confetti and interactions
- `photos/` - Ellah's photos (14 JPGs)
- `TODO.md` - Project progress (completed)

## How to View:
1. Open `C:/Users/goood/Desktop/Ellahs_birthday_website/index.html` in any web browser (Chrome, Firefox, Edge).
   - Windows: Double-click the file, or run `start index.html` in terminal from project dir.
2. Scroll for love letter, click for confetti, hover photos.
3. Click "View Full Photo Collage" for collage.html.

No server needed - pure HTML/CSS/JS!
